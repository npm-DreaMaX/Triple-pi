三次方进化

Triple-pi 独有优势

在 Pi 坚如磐石的核心之上，Triple-pi 注入了这些独有能力——让终端 AI 编码从高效走向极致。

01

🛡️ 内置安全门控

不再依赖外部容器或手动扩展。Triple-pi 内置细粒度权限系统——文件读写白名单、网络访问控制、危险命令拦截。你可以按项目粒度设定安全策略，让 AI 在受控区域内自由发挥。

02

👥 团队协作一流

共享项目配置、扩展集和对话模板。团队成员 clone 仓库后即刻拥有统一的 AI 开发环境。技能包、主题和提示模板随项目版本管理，无需各自配置。

03

📊 性能仪表板

实时预览 Token 消耗、成本曲线、缓存命中率、会话吞吐量。可视化图表助你洞察 AI 使用模式，做出更明智的模型选择和提示优化决策。

04

⚡ 对话模板引擎

将高频任务封装为零输入模板——代码审查、发布检查、重构建议等。一键触发完整工作流，AI 自动按步骤执行。支持模板市场，分享和复用团队最佳实践。

05

🎨 臻选主题系统

内置 8 套精研主题，从暗夜紫到极光蓝。每一款都经过可读性调优，支持终端色彩空间自适应。修改即时生效，样式永不遮挡。

06

🔍 增强上下文感知

智能识别项目结构——Mono Repo、微服务、多语言混合。自动加载最相关的上下文文件，减少手动指定。理解你的项目组织方式，而非盲目拼接文件。

功能全景

Triple-pi = Pi 的全部 + 更多

所有 Pi 的能力 Triple-pi 都原生提供，无需额外配置。

⚡

极简内核

仅提供 read / write / edit / bash 四种工具。不做子代理、不弹权限窗口、不内置待办——需要时通过扩展载入。

🧩

激进扩展性

Skills、Extensions、Packages、Themes——四种扩展机制让你按需构建。TypeScript 模块可替换内置工具、实现子代理、MCP 集成等任何功能。

🌳

树形会话分支

JSONL 树结构存储，原地分支不创建新文件。/tree 可视化浏览，/fork 回溯分叉，/clone 复制路径。多条探索共存，永不丢失。

🎯

四种运行模式

交互模式（全功能 TUI）、打印模式（-p 管道友好）、JSON 模式（事件流）、RPC 模式（进程集成）、SDK 模式（程序嵌入）。

💬

消息队列

Agent 工作期间随时提交转向/跟进消息。Enter 交付转向消息，Alt+Enter 交付跟进。Escape 取回未发消息。

🧠

7 级思考控制

off → max 七档推理深度。Shift+Tab 热切换，Ctrl+T 折叠思考块，Ctrl+O 折叠工具输出。

技术架构

清晰的分层结构

Triple-pi 采用三层架构：稳固的 Pi Runtime 基础层、增强的整合层、以及面向用户的体验层。

🎨 Triple-pi 体验层：独有功能、主题、模板、仪表板
│
🔌 Triple-pi 整合层：安全管理、团队协作、上下文增强
│
⚙️ Pi Runtime：编码代理 · 模型运行时 · 终端 UI · 扩展引擎
// Triple-pi = Pi 的超级增强版
// 100% 兼容 Pi 生态，叠加独有增强

import { createAgentSession } from "@earendil-works/pi-coding-agent";
import { tripleEnhance } from "triple-pi";

// 标准 Pi Session，注入 Triple-pi 增强
const session = await createAgentSession({ ... });
await tripleEnhance(session, {
  security: true,
  dashboard: true,
  teamShare: true,
  theme: "aurora"
});

// 获得 Pi 的全部能力 + Triple-pi 独有增强
await session.prompt("帮我重构这个模块");
